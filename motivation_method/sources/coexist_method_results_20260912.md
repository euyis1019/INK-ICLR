# Coexist-Merge：方法说明与主实验结果

更新：2026-09-12。本文只回答两个问题：我们最终选定的方法是什么，它在 CLIP、T5、LLM 三类设定上的主实验结果是什么。消融、机理讨论与异常值分析不在此列。

## 1. 方法

### 1.1 问题设定

给定一个预训练基座 $\theta_0$、在 $T$ 个任务上各自微调得到的专家 $\theta_1,\dots,\theta_T$，以及每个任务少量无标签的校准输入（CLIP 上每任务 256 张图，T5 与 LLM 上每任务 256 条提示），输出一个共享骨干 $\theta$。校准数据只知道任务归属，不带类别标签或答案；分类头、词表嵌入等按各自设定保留。评测集在最终评估前不被任何步骤读取。

### 1.2 每轮做什么

Coexist-Merge 是一个迭代过程。每一轮在当前合并模型 $\theta^{(r)}$ 上采集统计量，逐层求解一个二次拟合问题，再用留出数据决定接受多少更新。

对每个线性层 $\ell$（权重 $W^\ell$，输入 $h^\ell$），每个任务 $t$ 采两侧统计：

输入侧 $A_t^\ell=\mathbb{E}_{x\sim\mathcal{D}_t}\big[h^\ell(x)\,h^\ell(x)^\top\big]$，即当前合并模型在任务 $t$ 校准数据上的输入二阶矩，按 token 或 patch 展平，不减均值。

输出侧用专家作为教师。对一个校准样本，记教师分布 $p$、当前模型分布 $q$，定义逐类修正与 $\chi^2$ 散度

$$
a_c=\frac{p_c}{q_c}-1,\qquad
\chi^2(p\,\|\,q)=\sum_c q_c a_c^2,\qquad
\hat a_c=\frac{a_c}{\sqrt{\chi^2(p\,\|\,q)+\epsilon}} .
$$

令 $s_c^\ell=\nabla_{h^\ell}\log q_c$，则该层上的聚合修正方向是

$$
u_t^\ell(x)=\mathbb{E}_q\big[\hat a_c\,(s_c^\ell-\bar s^\ell)\big]
=-\frac{\nabla_{h^\ell}\,D_{\mathrm{KL}}(p\,\|\,q)}{\sqrt{\chi^2(p\,\|\,q)+\epsilon}},
$$

也就是教师到学生 KL 对该层输出的梯度，除以一个不参与求导的 $\chi^2$ 归一化因子。实现上一个 batch 只做一次反传：对逐样本的归一化 KL 求和后反传，backward hook 收集每层的 $u$。输出侧度量取其二阶矩

$$
G_t^\ell=\mathbb{E}_x\big[u_t^\ell(x)\,u_t^\ell(x)^\top\big],
$$

再做 Ledoit-Wolf 收缩，收缩强度由样本自己算出，逐层逐任务各不相同。两侧统计都按平均对角元归一化到 1，输入侧不收缩。

有了 $A_t^\ell$ 与 $G_t^\ell$，每层解正规方程

$$
\sum_{t=1}^{T} A_t^\ell\, X\, G_t^\ell=\sum_{t=1}^{T} A_t^\ell\, W_t^{\ell}\, G_t^\ell ,
$$

其中 $W_t^\ell$ 是专家 $t$ 的该层权重（转置到样本按行的约定）。这是一个 Kronecker 和形式的线性方程，没有闭式解，用对角预条件的共轭梯度从当前权重 $W^{\ell,(r)}$ 出发迭代至多 100 步。若某任务在该层的 $G$ 为零，则该任务不参与这一层的拟合。

得到候选 $X^\ell$ 后，不直接写回，而是在留出数据上做线搜索：更新 $W^{\ell}\leftarrow(1-\omega)W^{\ell,(r)}+\omega X^\ell$，$\omega\in\{0,\tfrac18,\tfrac14,\tfrac12,1\}$，选使留出教师 KL 最小的 $\omega$。CLIP 正式实现先做全局 $\omega$，再按 13 组块分别细化；T5 与 LLM 移植只做全局 $\omega$。留出 KL 定义为每任务先平均教师到学生 KL，再对任务等权平均，留出数据与采统计的校准数据不重叠。

最多四轮。所有轮次（含初始化）中留出 KL 最小的那个作为输出，同分取更早轮次。测试集只在这个模型上评一次。

### 1.3 起点与不动点

初始化用 Iso-C，尺度 1.3（CLIP 冻结配置）。迭代也可以从任何已有的合并结果出发，当作一个热插拔的后处理步骤；第 5 节汇总了换起点的结果。

### 1.4 与相关方法的关系

RegMean 只用输入侧 $A_t$，相当于令 $G_t\equiv I$，且只解一次。MaTS 用专家自己的 K-FAC 因子，统计量测在专家上而不是合并模型上。用学生分布的 Fisher 作输出侧度量时，教师与学生一致也不为零；这里的 $u$ 在一致时为零，度量只反映教师与学生的分歧。FeatCal 是前向顺序的单遍闭式校准；在 T5 上我们把它的目标插值机制放进本方法的迭代步作为扩展（第 3.2 节）。

### 1.5 冻结配置一览

| 项 | CLIP ViT-B/32（正式） | FLAN-T5 GLUE | MergeBench LLM |
|---|---|---|---|
| 校准 / 留出 | 每任务 256 / 256 张 | 每任务 256 / 256 条 train 提示 | 每域 256 / 256 条 `*_val` 提示，截 1024 token |
| 教师 | 专家 + 冻结分类头，逐类精确 | 专家贪心答案的 teacher-forced logits | 专家 top-128 logits |
| 起点 | Iso-C，尺度 1.3 | Iso-C 1.3（或任意已合并模型） | 任意已合并模型；自身默认 Iso-C 1.3 |
| 求解 | CG 100 步，从当前权重出发 | 同 | 同，按 transformer 层分段采统计 |
| 线搜索 | 全局 + 13 块 | 全局 | 全局 |
| 轮数 / 选轮 | 最多 4 轮，留出 KL 最小 | 同 | 同 |
| 不合并 | bias、LayerNorm 继承起点 | 同，嵌入按起点 | `embed_tokens`、`lm_head` 保留基座 |

## 3. FLAN-T5 GLUE

FusionBench 协议：八个 prompted GLUE 任务，输入 512 定长填充，生成后精确串匹配，STS-B 用 Spearman，MNLI 用 validation_matched。评测器与 FusionBench 公布值逐位一致。数据驱动方法只看 train split 的无标签提示。large 的专家是 LoRA r=16 合并为全权重后再做模型合并。

### 3.1 主表

| 方法 | base | large |
|---|---:|---:|
| Simple Average | 78.88 | 86.53 |
| Task Arithmetic | 78.89 | 87.30 |
| TIES | 80.01 | 86.16 |
| Iso-C 1.3 | 79.64 | 82.42 |
| TSV-M | 82.76 | 88.09 |

base 上留出 KL 选中目标插值 $\alpha=0.3$，large 上选中 $\alpha=0$，即原版。两处都是无标签判据的选择，不看 validation。

### 3.2 目标插值扩展

FeatCal 的做法是让合并模型在每层复现专家特征的一个插值。我们把它放进正规方程的右端：把 $A_t W_t$ 换成交叉二阶矩 $C_t=\mathbb{E}[h_s h_t^\top]$，其中 $h_t=\alpha\,h_{\text{expert}}+(1-\alpha)\,h_{\text{student}}$，其余步骤不变。base 上 $\alpha=0.3$ 比原版高 0.7 分，large 上 $\alpha=0.3$ 反而低 1 分；留出 KL 在两种规模上都选对了方向（base 0.0184 对 0.0213，large 0.0224 对 0.0027）。

## 6. 结论怎么说，边界在哪

能主张的是：在 CLIP 九格、T5 两种规模、两个 LLM 模型族共十格上，Coexist-Merge 在无标签校准、val 或留出选点的协议下高于同环境的已发表基线，并且叠在任何官方配置的基线之上都能把它抬到同一水平（LLM 上只有一格例外）。

需要如实写的有三条。LLM 上 RegMean a=0.5 起点一格 GSM8K 下降 1.1 分，三域持平；Llama 上六个 Coexist 模型的 IFEval 全部收敛到 13 到 17，起点最高的 TA 被拉低 5 分，三域宏平均最高仍是 TSV-M 基线本身；同一起点换校准 seed，留出 KL 轨迹重合到第三位小数，GSM8K 极差却有 2.3 分。这些都原样保留，留待分析。
