\section{从合并起点到当前模型的修正需求}
\label{sec:motivation}

模型合并将同一预训练模型独立微调得到的专家整合为单一模型。权重平均与任务算术提供了直接的参数组合方式~\citep{wortsman2022model,ilharco2023editing}；Fisher merging、RegMean 及 MaTS 进一步利用任务相关的敏感度或输入统计，区分不同参数方向的作用~\citep{matena2022fisher,jin2023regmean,tam2024mats}。这些工作自然引出一个后续问题：\textbf{给定一个已有合并结果，如何依据它当前的功能缺口继续修正？}

我们在 CLIP ViT-B/32 八任务设置上，固定专家、无标签校准数据和修正规则，从 Average、RegMean 和 Iso-C~\citep{marczak2025no} 出发进行配对诊断。每轮最多使用 100 步共轭梯度（CG），最多执行四轮；以下均为 seed 0 的机制观察，数据划分与额外对照见附录~\ref{app:protocol}。

\paragraph{起点的功能差异可以被修复。}
Average 与 RegMean 在同一独立诊断集上的准确率差距由 $22.36$ 缩小到 $0.15$ 个百分点（图~\ref{fig:motivation}a），预测分布的 JS 散度由 $0.13847$ 降至 $0.00412$。终态完整测试仅差 $0.24$ 个百分点，而逐层相对参数距离的中位数仍为 $2.53\%$。因此，对起点的适配可以表现为功能接近，无需消除全部参数差异。该现象有明确边界：Iso-C 与增量范数匹配的未拉平起点在四轮后仍相差 $8.25$ 个测试准确率百分点。我们研究的是\emph{降低对常用合并起点的敏感性}，而非任意初始化的同解收敛。

\paragraph{一次接受更新后，仍有继续修正的空间。}
Average 的完整测试准确率从第一轮的 $83.712\%$ 提高到第四轮的 $85.312\%$（图~\ref{fig:motivation}b）。冻结初始统计、继续相同轮数得到 $84.519\%$；将第一次求解延长到 CG400 得到 $84.565\%$。这些对照分别说明，后续更新有用，而继续求解同一个固定统计问题没有复现刷新流程的全部收益。CG400 仅是有限求解预算对照，不代表充分收敛或等耗时比较。

\paragraph{更新改变了下一次修正的工作条件。}
一次合并会改变上游输入、当前预测及下游传播，即使专家与图像保持固定，$A$ 和 $G$ 也会变化。Average 首轮前后，固定诊断图像上的纠正梯度余弦中位数为 $0.248$，实际求解度量的余弦为 $0.553$（图~\ref{fig:motivation}c）。进一步固定\emph{同一个}第一轮 checkpoint，使用当前与初始统计构造并接受更新，独立诊断 KL 分别降低 $0.080560$ 与 $0.044534$。这种同状态干预将统计变化与更新效果联系起来。跨 block 干预还表明，本块权重不变时，周围网络的更新也能改变其统计与修正效果（附录图~\ref{fig:context}）。

刷新收益依赖状态：四轮刷新相对冻结的测试增益在 Average、Iso-C、RegMean 上分别为 $0.794$、$0.115$、$0.003$ 个百分点；后期度量逐渐稳定。因而，现有证据支持按当前状态重新测量的策略，尚未证明所有起点、所有后续轮次都必须刷新。

\paragraph{从观察到方法。}
上述结果指向同一设计原则：\textbf{以当前合并模型为参照，测量各任务现在允许且需要的修正；接受修正后，再适配新的网络状态。}输入二阶矩描述当前访问的方向，教师--学生 KL 纠正的二阶矩描述尚存分歧所对应的输出轴。将二者与专家参数锚点结合，得到下一节的迭代合并方法。
