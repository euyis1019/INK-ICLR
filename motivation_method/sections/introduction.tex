\section{引言}
\label{sec:introduction}

模型合并旨在将多个任务专家的能力保留在一个共享模型中，降低联合重训的成本，并减少对原始训练数据的依赖~\citep{wortsman2022model,ilharco2023editing}。任务向量修正、冲突消解与谱子空间方法改善了参数的组合方式~\citep{yadav2023ties,marczak2025no}；RegMean、MaTS 等方法进一步利用校准统计匹配专家行为~\citep{jin2023regmean,tam2024mats}。但合并模型与独立专家之间仍有差距，如何继续修正这些差距是本文关注的问题。

\textbf{专家保持固定，共享模型的修正需求却随更新而变化。}前层更新改变后层输入，预测变化也会改变剩余的专家分歧。初始统计确定的代理因而可能偏离当前需求，单纯提高求解精度未必能修复这一偏差。数值求解还可能因有限样本而病态：直接求逆放大噪声，过强的正则化削弱任务信息。MaTS 已展示迭代求解的价值~\citep{tam2024mats}；我们进一步考察更新后重新估计统计的作用。

RegMean++ 已将合并网络的层内与跨层依赖纳入回归目标~\citep{nguyen2026regmeanpp}，IterIS 在 LoRA 合并中交替推断特征与求解~\citep{chen2025iteris}。本文以固定专家与当前共享模型的剩余预测分歧为反馈，同时更新层输入统计与输出侧修正统计。

由此，我们提出 \textbf{\method{}（CM）}。CM 从已有合并结果出发，默认使用 Iso-C，在少量无标签数据上测量当前模型的修正需求，以专家参数为锚点，用有限步迭代逐层求解候选权重，再根据独立留出集上的教师学生 KL 选择更新幅度。接受更新后，CM 在新状态上重新测量，形成“测量、求解、选择、重测”的反馈过程。

多轮诊断显示，修正度量在更新后变化并逐步趋稳。在 Average 对照中，每轮重测比同为四轮的固定统计版本提高约 $0.79$ 个百分点；将初始系统单轮求解增至 400 步仍未达到该结果。九格 CLIP 配置均较 Iso-C 起点缩小了与独立专家的差距。T5 与 LLM 也有多种起点获得改善，但 LLM 部分指标回退，表明收益依赖任务和初始化。

本文的主要贡献如下：
\begin{itemize}
  \setlength{\itemsep}{2pt}
  \item \textbf{分析固定代理合并的稳定性与状态适应性局限。}结合病态系统分析与配对诊断，区分继续求解和重测的收益；Average 对照显示，延长初始求解未能达到重测效果。
  \item \textbf{提出以当前共享模型为反馈的 CM。}结合当前修正统计、专家锚定求解、独立留出集选步与接受后的重测，在视觉、NLP 与 LLM 设定中验证这一迭代框架。
  \item \textbf{验证算法兼容性与初始化适配能力。}CM 可接续 WeightAvg、RegMean、Iso-C、TSV-M 等方法，无需改动原合并规则；已测 CLIP 与 T5 对照中，多种起点得到改善，部分起点间的性能差距缩小。
\end{itemize}
